# GulaschGo

Browser race game (PS1-era low-poly look). First playable slice: **game-basis**.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

## Controls

| Key | Action |
| --- | --- |
| W | Accelerate |
| S | Brake / reverse |
| A / D | Steer |
| R | Restart race |

## Slice

Short curved-track delivery race vs one rival, classic rear chase cam, bilingual (DE/EN) finish stub.

Process docs: `docs/sdlc/`.
